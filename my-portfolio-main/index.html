A brief description of your awesome project and what tools you used.

IoT Smart Fan Indicator

An Internet of Things (IoT) system built using Arduino IDE and integrated with Firebase Realtime Database. The application allows users to manually adjust temperature thresholds to activate specific status alerts. The system triggers three LED lights to dynamically indicate the real-time temperature state:

  • Red LED: Indicates High Temperature
  • Yellow LED: Indicates Medium Temperature
  • Green LED: Indicates Normal Temperature
